## VINHERIA AGNELLO

Checkpoint 03-JavaScript

## DESCRIÇÃO

Sistema simples para controle de estoque de vinhos.

## TECNOLOGIAS UTILIZADAS

. HTML
. CSS
. JavaScript

## ESTRUTURA DO PROJETO 

vinheria-agnello-checkpoint03/
│
├── index.html
├── README.md
│
└── src/
    ├── css/
    │   └── style.css
    │
    └── js/
        └── script.js

. index.html — página principal do site.
. README.md — descrição do projeto e informações da entrega.
. src/css/style.css — estilos e aparência da página.
. src/js/script.js — código JavaScript para o sistema de cadastro e controle de estoque de vinhos.

## FUNCIONALIDADES (CONSOLE DO NAVEGADOR)

. Listagem dos vinhos.
. Adição de vinhos.
. Verficação de estoque baixo.
. Cálculo do estoque total.
. Exibição dos nomes dos vinhos em letra maiúsitulas.
